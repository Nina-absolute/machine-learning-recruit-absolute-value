## 三、 关键原理与零基础概念解释
1. **矩阵乘法 `@`**：左矩阵的列数必须等于右矩阵的行数，例如 `(1, 2) @ (2, 4) -> (1, 4)`。
2. **逐元素乘法 `*`**：要求两个矩阵形状相同（或满足广播机制），对应位置相乘。
3. **ReLU 激活函数**：`np.maximum(0, Z1)`。把负数变成 0，正数保持不变。
4. **Sigmoid 函数**：$p = 1 / (1 + e^{-Z_2})$。将实数映射到 (0, 1) 区间，代表二分类概率。
5. **二元交叉熵损失 (BCE)**：$L = -[y \log(p) + (1-y) \log(1-p)]$。
6. **`.mean()` 归约**：对 Batch 内所有样本的损失求平均。这会导致在反向传播时，梯度需要除以样本数 $N$（即多出一个 $\frac{1}{N}$ 的系数）。
7. **PyTorch `autograd`**：PyTorch 的自动求导引擎。`loss.backward()` 会沿着计算图反向走一遍，自动计算所有 `requires_grad=True` 的张量的梯度，并保存在 `.grad` 属性中。

## 五、 计算图与链式法则
*(注：计算图海报以 `computation_graph.png` 形式单独交付，此处描述其核心逻辑。)*

**前向传播**：
$$
Z_1 = X W_1 + b_1 \rightarrow A_1 = \text{ReLU}(Z_1) \rightarrow Z_2 = A_1 W_2 + b_2 \rightarrow p = \text{Sigmoid}(Z_2) \rightarrow L = \text{BCE}(p, y)
$$

**反向传播（链式法则从后向前）**：
1. **输出层误差**：$\frac{\partial L}{\partial Z_2} = \frac{1}{N}(p - y)$
2. **第二层参数梯度**：$\frac{\partial L}{\partial W_2} = A_1^T \frac{\partial L}{\partial Z_2}$，$\frac{\partial L}{\partial b_2} = \sum_{i=1}^N \frac{\partial L}{\partial Z_2}$
3. **传回隐藏层**：$\frac{\partial L}{\partial A_1} = \frac{\partial L}{\partial Z_2} W_2^T$
4. **激活函数反向**：$\frac{\partial L}{\partial Z_1} = \frac{\partial L}{\partial A_1} \cdot (Z_1 > 0)$
5. **第一层参数梯度**：$\frac{\partial L}{\partial W_1} = X^T \frac{\partial L}{\partial Z_1}$，$\frac{\partial L}{\partial b_1} = \sum_{i=1}^N \frac{\partial L}{\partial Z_1}$

## 六、 实验结果与核心错误分析

### 1. 单样本实验结果
单样本下，NumPy 手算梯度与 PyTorch 自动求导结果完全一致，最大绝对误差通常在 $10^{-7}$ 级别，输出 `✅ 结果一致`。

### 2. 小批量实验结果与错误分析（重点）
**初始错误现象**：小批量版本运行后，所有梯度对比均显示 `❌ 结果不一致`，最大绝对误差非常大（通常是 $10^{-1}$ 或 $10^0$ 级别）。

**错误原因分析**：
在 NumPy 手写反向传播时，我们计算损失 `L` 使用了 `.mean()`（对 Batch 求均值），但在反向传播推导梯度时，**忘记除以样本数 $N$（即 Batch Size）**。
- 数学推导：均值求导会多出一个 $\frac{1}{N}$ 系数，即 $\frac{\partial L}{\partial Z_2} = \frac{1}{N}(p - y)$。
- NumPy 代码：初始错误代码写成了 `dL_dZ2 = (p - y)`，漏掉了 $\frac{1}{N}$。
- PyTorch 代码：`torch.nn.functional.binary_cross_entropy` 默认 `reduction='mean'`，底层 autograd 自动带上了 $\frac{1}{N}$。
- 结果：NumPy 计算出的梯度比 PyTorch 大了整整 $N$ 倍（本例中 $N=4$，即大了 4 倍）。

**修正方案**：
在 NumPy 反向传播的第一步，除以 Batch Size $N$：
```python
dL_dZ2 = (p - y) / N   # 修正核心
```
修正后，NumPy 与 PyTorch 梯度再次完全一致，最大绝对误差降至 $10^{-7}$ 以下，输出 `✅ 结果一致`。

### 3. 小批量变化总结
- **形状变化**：所有与样本数 $N$ 相关的中间变量（$X, Z_1, A_1, Z_2, p, y$）的第 0 维从 1 变成了 $N$。参数（$W_1, b_1, W_2, b_2$）的形状完全不变。
- **公式变化**：Loss 引入了 `.mean()` 归约；偏置梯度引入了跨 Batch 的 `np.sum(..., axis=0, keepdims=True)` 求和；所有梯度引入了 $\frac{1}{N}$ 的缩放系数。
