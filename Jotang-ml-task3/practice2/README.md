# Task 3：两层神经网络的前向传播与反向传播

## 文件说明

- `forward_backward.py`：单样本前向传播、NumPy 手动反向传播、PyTorch autograd 验证，以及四组参数梯度逐项比较。
- `change_batch.py`：将输入扩展为 3 个样本，观察中间结果形状和梯度计算的变化。
- `computation_graph.png`：仅包含网络计算图的海报图片。

运行方式（在已安装 NumPy、PyTorch 的环境中）：

```bash
python forward_backward.py
python change_batch.py
```

## 1. 计算图

见单独图片 `computation_graph.png`。网络结构：

`X → Linear → ReLU → Linear → Sigmoid → BCE Loss`

粉色虚线表示梯度从损失向前传播的方向；实线表示前向计算方向。

## 2. 单样本实验参数表

| 变量 | 形状 | 示例值 | 含义 |
|---|---|---|---|
| `X` | `(1, 2)` | `[[1.0, 2.0]]` | 一个样本、两个输入特征 |
| `y` | `(1, 1)` | `[[1.0]]` | 真实二分类标签 |
| `W1` | `(2, 2)` | `[[0.1, 0.2], [0.3, 0.4]]` | 第一层权重 |
| `b1` | `(1, 2)` | `[[0.1, 0.1]]` | 第一层偏置 |
| `Z1` | `(1, 2)` | 由 `X @ W1 + b1` 计算 | 第一层线性输出 |
| `A1` | `(1, 2)` | `ReLU(Z1)` | 隐藏层激活输出 |
| `W2` | `(2, 1)` | `[[0.2], [-0.3]]` | 第二层权重 |
| `b2` | `(1, 1)` | `[[0.05]]` | 第二层偏置 |
| `Z2` | `(1, 1)` | 由 `A1 @ W2 + b2` 计算 | 输出层 logit |
| `Y_hat` | `(1, 1)` | `Sigmoid(Z2)` | 预测为正类的概率 |
| `loss` | 标量 `()` | BCE | 二元交叉熵损失 |

## 3. 梯度形状表

| 梯度 | 形状 | 含义 |
|---|---|---|
| `dL_dZ2` | `(1, 1)` | 损失对第二层线性输出的梯度 |
| `dL_dA1` | `(1, 2)` | 损失对隐藏层激活输出的梯度 |
| `dL_dZ1` | `(1, 2)` | 损失对第一层线性输出的梯度 |
| `dW1` | `(2, 2)` | 第一层权重梯度 |
| `db1` | `(1, 2)` | 第一层偏置梯度 |
| `dW2` | `(2, 1)` | 第二层权重梯度 |
| `db2` | `(1, 1)` | 第二层偏置梯度 |

## 4. 反向传播关键公式

单样本情况下，Sigmoid 与 BCE 组合后：

`dL_dZ2 = Y_hat - y`

然后沿链式法则反向计算：

```text
dW2 = A1.T @ dL_dZ2
db2 = sum(dL_dZ2, axis=0, keepdims=True)
dL_dA1 = dL_dZ2 @ W2.T
dL_dZ1 = dL_dA1 * (Z1 > 0)
dW1 = X.T @ dL_dZ1
db1 = sum(dL_dZ1, axis=0, keepdims=True)
```

## 5. 从单样本改成小 batch

`change_batch.py` 使用 `N=3` 个样本：

| 变量 | 单样本 | 3 个样本 |
|---|---|---|
| `X` | `(1, 2)` | `(3, 2)` |
| `y` | `(1, 1)` | `(3, 1)` |
| `Z1`、`A1` | `(1, 2)` | `(3, 2)` |
| `Z2`、`Y_hat` | `(1, 1)` | `(3, 1)` |
| `dL_dZ2` | `(1, 1)` | `(3, 1)` |
| `dL_dA1`、`dL_dZ1` | `(1, 2)` | `(3, 2)` |
| `W1`、`dW1` | `(2, 2)` | `(2, 2)` |
| `b1`、`db1` | `(1, 2)` | `(1, 2)` |
| `W2`、`dW2` | `(2, 1)` | `(2, 1)` |
| `b2`、`db2` | `(1, 1)` | `(1, 1)` |

参数与参数梯度形状不随 batch 大小改变。中间变量增加样本维度。因为 BCE 默认对 batch 中样本求平均，NumPy 手动反向传播需要在 `dL_dZ2 = (Y_hat - y) / N` 中除以样本数 `N`。

## 6. 验证标准

两个脚本都会输出 NumPy 与 PyTorch 的梯度形状、数值、最大绝对误差，以及 `np.allclose` 的比较结果。四组参数梯度均显示一致，且误差接近 0，即验证通过。
