### 1. 人工智能、机器学习与深度学习之间有什么关系？

### 2. 监督学习和无监督学习有什么区别？请各举一个例子。
- 监督学习给定数据的标签，相当于预设出具体的正确答案。  
  例：分类垃圾邮件（一定要区分是垃圾邮件还是不是）

## 关于模型

### 3. 数据、特征和标签分别是什么？训练集、验证集和测试集各有什么用途？
数据就是机器学习需要分析的样本。  
特征是数据具有的属性，相当于机器实际分析、做出判断的依据。  
标签就是机器学习最终本应该得到的那个正确答案，也就是机器需要通过学习预测的实际性质。

训练集用于让机器不断更新参数，相当于日常作业增强熟练度；  
验证集用于选择超参数/最优 checkpoint，相当于模拟考用于检验学习策略；  
测试集用于评价最终模型的泛化能力，相当于最后最后的期末考试。

### 4. batch size是什么？有什么影响？
batch size 是一次参数更新用的样本数，大概相当于每次日常作业用的作业量？  
太少：GPU利用率低，效率低下；梯度方差大；  
太大：可能直接爆显存，跑不起来；梯度方差更小相对更稳。

* ai 补充：  
  小 batch → 梯度噪声大 → 容易被"推"出尖锐的坑 → 停在平坦的盆地 → 泛化可能更好。  
  大 batch → 梯度稳 → 滑进某个坑就不动了 → 可能是尖锐的坑 → 泛化可能稍差。

### 5. 什么是模型和模型参数？
模型就是从数据到标签的预测方式，本质上是从输入到输出的映射函数。  
模型参数就是模型内部需要学习确定的数值，大概类似于机器里面的某种旋钮？本质上是函数中含有的参数。

### 6. 神经网络由哪些基本部分组成？什么是激活函数？为什么要激活函数？请介绍几种常见的激活函数。
神经网络示意图：  
输入 → 隐藏层（激活函数夹在线性层之间~~大概类似于变压器？~~） → 输出

激活函数通过计算加权和并加上偏置（也就是线性层的输出）来确定神经元是否应该被激活。简单来说就是对输入信息做出一定非线性处理。

常用的有：
1. ReLU  
   $\mathrm{ReLU}(x) = \max(x, 0)$，求导表现得特别好：要么让参数消失，要么让参数通过。这使得优化表现得更好，并且 ReLU 减轻了困扰以往神经网络的梯度消失问题。
2. Sigmoid  
   squashing function, 把范围在实数的任意输入压缩为(0, 1)中的某个值。  
   $\mathrm{sigmoid}(x) = \frac{1}{1 + \exp(-x)}$
3. Tanh  
   双曲正切函数，与 Sigmoid 类似，把输入压缩到(-1, 1)。

### 7. 矩阵如何求导？提前学习该部分数学。
例如：

对于：
$$
\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \end{bmatrix}, \qquad \mathbf{y} = \begin{bmatrix} y_1 \\ y_2 \end{bmatrix}
$$

要求 $x$ 对 $y$ 的偏导数：则最终求出来也是个矩阵。

$$
J_{ij} = \frac{\partial y_i}{\partial x_j}
$$

$$
J =
\begin{bmatrix}
\frac{\partial y_1}{\partial x_1} & \frac{\partial y_1}{\partial x_2} \\
\frac{\partial y_2}{\partial x_1} & \frac{\partial y_2}{\partial x_2}
\end{bmatrix}
$$

### 8. 怎么用矩阵乘法表示神经网络的全连接层前向传播过程？

全连接层也就是线性层。以 batch size 为 64，且只有线性层 → 激活函数 → 线性层 为例：

$$
\mathbf{Z}_1 = \mathbf{X}\mathbf{W}_1^T + \mathbf{b}_1
$$

$$
\mathbf{H} = \mathrm{ReLU}(\mathbf{Z}_1)
$$

$$
\mathbf{O} = \mathbf{H}\mathbf{W}_2^T + \mathbf{b}_2
$$

| 名字 | 形状 | 含义 | 谁产生 |
| --- | --- | --- | --- |
| $\mathbf{X}$ | $(64,2)$ | 输入数据 | DataLoader |
| $\mathbf{W}_1$ | $(16,2)$ | 第一层权重 | `nn.Linear(2,16)` |
| $\mathbf{b}_1$ | $(16,)$ | 第一层偏置 | `nn.Linear(2,16)` |
| $\mathbf{Z}_1$ | $(64,16)$ | 隐藏层加权输入 | $\mathbf{X}\mathbf{W}_1^T + \mathbf{b}_1$ |
| $\mathbf{H}$ | $(64,16)$ | 隐藏层激活输出 | $\mathrm{ReLU}(\mathbf{Z}_1)$ |
| $\mathbf{W}_2$ | $(2,16)$ | 第二层权重 | `nn.Linear(16,2)` |
| $\mathbf{b}_2$ | $(2,)$ | 第二层偏置 | `nn.Linear(16,2)` |
| $\mathbf{Z}_2$ | $(64,2)$ | 输出层线性变换结果 | $\mathbf{H}\mathbf{W}_2^T + \mathbf{b}_2$ |
| $\mathbf{O}$ | $(64,2)$ | 最终输出 logits | 模型输出 |

### 9. 前向传播与反向传播分别在做什么？损失函数、梯度和学习率在训练过程中扮演什么角色？
- 前向传播：输入 → 隐藏层 → 输出，通过矩阵乘法、线性处理、激活函数，得到前向缓存和 logits。
- 反向传播：通过对损失和中间缓存的分析，最终得到梯度。

- 损失函数：输入 logits，结合真实类别的概率，得到损失。分析损失让我们看见训练结果与正确答案的具体差距（比只有对错之分的 accuracy 更精确）
- 梯度：反向传播时损失函数对每个参数的偏导数组成的向量，事实上负梯度方向指示着减小 Loss 的方向，梯度大小（也就是模长）代表了 Loss 随参数变化的变化速率。
- 学习率：参数更新的步长，也就是参数更新的幅度。

### 10. 优化器是什么？有哪些？
优化器是一种能由参数、超参数、梯度分析，得到更有利于减小损失的新参数的数学处理方法。

常见的有：
1. **SGD = stochastic gradient descent, 随机梯度下降**  
   每次用一个 batch 的梯度，直接更新参数。  
   既然梯度指向 loss 增大，那么让参数走反方向就好了。  
   $\theta \leftarrow \theta - \eta \cdot g$  
   $\theta$ 是当前的参数（$W, b$），$g$ 是梯度，$\eta$ 是学习率。
   ```python
   optimizer = torch.optim.SGD(net.parameters(), lr=0.01)
   ```

2. **Momentum 动量法**  
   $v \leftarrow \beta \cdot v + g$  
   $\theta \leftarrow \theta - \eta \cdot v$  
   其中 $v$ 是速度，$\beta$ 是动量系数。  
   本质上是 SGD 2.0，与上次方向相同则激进累加，相反则保守抵消。

3. **AdaGrad = Adaptive Gradient，梯度自适应**  
   $s \leftarrow s + g^2$  
   $\theta \leftarrow \theta - \frac{\eta}{\sqrt{s} + \epsilon} \cdot g$  
   其中 $s$ 是梯度平方的累积，$\epsilon$ 是防止除零的小常数（1e-8）。  
   效果类似于 Momentum，本质上是根据累积梯度调控参数更新速率（梯度大减得少，梯度小减得多）。  
   当然此处有个华点，相信大家都发现了：  
   平方累出来的 $s$ 事实上一直增大，所以到一定程度后，对参数更新速率的影响变得极其有限。此时引入一种新方法，RMSProp 就是这样一种可以定时删去之前累计的改良版方案。

4. **Adam**  
   综合 Momentum 和 RMSProp 两种方法优点，可谓集大成者，因此极其适合判断不好学习率的初级阶段使用。

### 11. 什么是过拟合，欠拟合，正则化？
- 过拟合就是模型表达过于复杂，甚至于把训练集的所有特征都学习了，包括那些干扰预测的无关噪声。泛化能力差，在训练集中表现好，但在验证集/测试集的表现差。
- 欠拟合就是模型表达能力不足，前向传播算出来的 logits 和标签差距大，损失大，无法拟合。
- 正则化，一类主动对参数、输入层、隐藏层等进行一定处理，用于解决过拟合问题的方法。

接下来解释具体的几种方法，增强直观感受：
1. **L2 正则化（权重衰减）**  

   事实上，当某些特征对应的权重异常大，同时泛化能力很差，基本上可以确诊过拟合了。也就是说，模型过于关注一些不普适的细节，而忽略了我们希望它学习到的那些本质。  
   针对这种情况，L2 正则化通过引入正则化系数，在每个 batch 的参数更新（即优化器中）时给权重乘上一个小于一的系数，实现权重衰减。  
   ps：当然正则化系数通常结合对照实验，在一个合理的范围内选取。太大了容易衰减过度，反而欠拟合；太小了则无法解决过拟合。  
   同时，采取这种方法一般会牺牲一点点 train_loss，但换取了更好的 val_loss，更好的泛化能力。

2. **Dropout**  
   和 L2 正则化类似，Dropout 同样适用于某些神经元的权重过大的情况。不过 Dropout 没有对权重下手，而是选择**每个 batch 的前向传播时随机关闭**那些承受了太多的神经元，从而让其他平时摸鱼的神经元也能得到锻炼。  
   ps：神经元数量变化的同时，为保证输出期望不变（期望相同就可以保证后续评估不采用 Dropout 时，仍然保证与处理后的隐藏层输出尺度相同，最终求加权和时不至于导致输出错误），对于那些未被丢弃的神经元的输出，需要按期望适当增大。

3. **早停**  
   监控 val loss，在它开始持续上升时停止训练，并保存这个 epoch 结束后的 best checkpoint。

### 12. 为什么不同项目最好使用不同的 Python 虚拟环境？

因为运行 scikit-learn 等等都需要**依赖** numpy，需要使用的包必须与它们依赖的包版本要求兼容。  

猜测的原因：由于 numpy 等库持续更新，那么就必然会有函数名删改等等变化。出于现实考量，我们不可能每次更新都手动改代码，所以不如直接使用不同的虚拟环境，避免全局设置统一时发生依赖冲突，也就是包和包之间不兼容。

### 13. CPU 和 GPU 各自擅长什么？训练神经网络为什么经常使用 GPU？
CPU 作为中央处理器，核心数少，擅长逻辑推理（复杂`if else`等等）。  

GPU 作为图像处理器，核心数多，但每个都比较弱，擅长并行巨量任务。

使用 GPU 原因：
1. 矩阵乘法本来就类似一次性乘完所有数，与 GPU 擅长并行任务的优势贴合。
2. 多次训练需要海量计算，使用核心数更多的 GPU 速度更快。

### 14. CUDA 是什么？它、显卡驱动与 PyTorch 之间大致是什么关系？
CUDA 是 compute unified device architecture 统一计算设备架构。NVIDIA 提供的 GPU 编程接口。 

简单来说就相当于把分配显存、启动内核、复制数据等等全部打包成一个名叫 CUDA 的接口，让程序员不用再把数组包装成像素交给 GPU 计算，而是直接使用 `device = 'cuda'`的命令就能实现 GPU 调用。

流程图 be like:
```
朴素理解版：  
使用 PyTorch 这种框架写 Python 命令（预备把张量推送到 GPU 上处理）  
    ↓  
CUDA 把 Pytorch 命令转化为 CUDA 对应指令（Pytorch 传话给 CUDA）  
    ↓  
CUDA 指令经驱动程序传输到 GPU 命令队列里（CUDA 翻译，驱动传话给 GPU）  
    ↓  
GPU 硬件执行计算，最终把结果存在 GPU 显存里（GPU 听话，执行计算）  
    ↓  
CUDA 再把结果从显存复制回主机内存（CUDA 的 `cudaMemcpy` 传回计算结果）
```
