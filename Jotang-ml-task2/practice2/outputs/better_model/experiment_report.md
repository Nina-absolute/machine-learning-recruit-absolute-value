1. 模型骨干替换
   - 原版：简单 3 层 CNN（参数量少，特征提取能力弱）
   - 改进：预训练 ResNet-18（ImageNet 权重，特征提取能力强）
   - 效果：收敛更快，验证/测试准确率显著提升，对姿态、背景、遮挡更鲁棒

2. 损失函数改进
   - 原版：普通交叉熵
   - 改进：交叉熵 + Label Smoothing（0.1）
   - 效果：缓解过拟合，训练更稳定，泛化误差更小

3. 学习率调度
   - 原版：固定学习率 1e-3
   - 改进：余弦退火（1e-3 → 1e-5）
   - 效果：后期更精细收敛，避免在最优解附近震荡，验证 loss 更平滑

4. 测试时增强（TTA）
   - 原版：单次预测
   - 改进：原图 + 水平翻转，取平均
   - 效果：推理鲁棒性提升，测试准确率通常再涨 0.5%～1.5%

5. 训练轮数
   - 原版：10 轮
   - 改进：15 轮
   - 效果：配合余弦退火和标签平滑，模型充分收敛

6. 输出形式
   - 原版：保存 best_model.pth，只打印结果
   - 改进：不保存模型，直接生成 Loss / Accuracy 四线对比图
   - 效果：一张图直观对比 CNN 与 ResNet-18 的收敛速度与最终精度
