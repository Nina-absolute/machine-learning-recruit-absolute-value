### 需要注意的是：
**学习笔记**中：
- `README.md`带有`*`标注或者名称含有`comprehensive`的是复习自用版笔记，更加详尽但书写风格也更加自由；
- 名称中带有`answer`的是只含题目要求内容的笔记，**可以只检查这部分的提交**。

**源代码**中：
- 带有`final`的是程序实际运行用的纯代码无注释版，**可以只检查这部分的复现效果**
- 带有`comprehensive`的是带有详细注释的自用复习版，辅助笔记食用:D
